Works with your AI

Your AI can pull the same rankings published on this site and help you build your bracket from real numbers.

Connect this site to Claude, Cursor, or any other MCP client (MCP, the standard way AI apps connect to outside tools). It is free, and it takes about a minute.

1. Copy the server address

https://mcp.fillmybracket.com/mcp

2. Add it to your AI

Claude Code: one command 
claude mcp add --transport http fill-my-bracket https://mcp.fillmybracket.com/mcp
Claude Desktop or Cursor: paste into the MCP settings 
{
  "mcpServers": {
    "fill-my-bracket": {
      "url": "https://mcp.fillmybracket.com/mcp"
    }
  }
}
